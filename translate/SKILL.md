# Translate

選択範囲またはプロンプト内の文章を翻訳する。訳出方向、用途の区別、保持する要素、不明箇所の扱いは[翻訳規範](..# local content excludedtranslation-rules.md)を正とする。

## Procedure

1. 対象範囲を確認する。
  - 選択範囲がある場合は、その範囲だけを対象にする。
  - プロンプト内の文章を訳す場合は、チャットに出力する。
  - 文書全体の対訳版を作る依頼は用途Bとして扱う。
2. 用途を判定する。
  - 既定は読解のための翻訳（用途A）とする。
  - 対訳版・併記版・既存英語版更新は用途Bとする。
  - どちらか判断できない場合は確認する。
3. 翻訳する。
  - 日本語は英語へ、それ以外の言語は日本語へ訳す。指定があれば指定に従う。
  - company-specific context、進化分子工学、生化学実験、LLM活用の文脈を前提に訳語を選ぶ。
  - 固有名詞、遺伝子名、タンパク質名、assay名、ツール名、モデル名、配列、数値、単位は原表記・原ケースを維持する。
4. 出力する。
  - 選択範囲がある場合は、原文を削除・差し替えず、訳文を原文の下部に差し込む。入れ替え・差し替え指示がある場合のみ例外とする。
  - プロンプト内の文章はチャットに出力する。

## Output

- 用途Aでは、必要な専門用語にだけ簡潔な説明を付ける。
- 用途Bでは、説明・判断・補足を追加せず、原文と同じ構成・情報量にする。
- 感想、要約、余分な見出しは追加しない。

## Hard constraints

- 原文にない事実、判断、根拠、注意書きを追加しない。
- 判読不能・抽出不能・未確認の固有名詞を推測で訳さない。
- 既存のリンク、メンション、コード、数式、表、ファイルを壊さない。
- 変更範囲、原意・事実保持、構造保持は[編集ガードレール](..# local content excludedediting-guardrails.md)に従う。
